## ข้อจำกัดที่ยังเหลือ

1. **ยังไม่ได้ลองอ่านรูปด้วย Claude จริง:** ต้องลองในลิงก์ claude.ai ด้วยรูปจริงสักเพลง แล้วดูว่าคอร์ดตรงตำแหน่งแค่ไหน
2. **ลิงก์ github.io ไม่ซิงก์ข้ามเครื่อง:** ถ้าต้องการ ต้องมีฐานข้อมูลภายนอก (ดูด้านล่าง)
3. **ยังไม่ได้ทดสอบบนอุปกรณ์จริง:** iPhone/Android จริง การล็อกจอ และการสลับแอป
4. **ยังไม่มี service worker:** ลิงก์ github.io เปิดครั้งแรกตอนไม่มีเน็ตไม่ได้
5. **เวลารวมเป็นค่าประมาณ:** คิดจาก BPM และจำนวนห้อง ไม่ใช่ความยาวเพลงจริง และไม่นับช่วงพัก
6. **เพลงที่ 4–6 ยังตรวจรอบสองไม่เสร็จ:** ทุกเพลงยังไม่ได้ตรวจกับเพลงจริง

| ทางเลือก | ข้อดี | สิ่งที่เจ้าของต้องทำ |
|---|---|---|
| ใช้ลิงก์ claude.ai เป็นลิงก์ของวง (พร้อมแล้ว) | ไม่ต้องตั้งระบบเพิ่ม มีสิทธิ์และอ่านรูปให้ | สมาชิกต้องมีบัญชี claude.ai และเจ้าของแชร์ให้ |
| Supabase (Postgres + ล็อกอินด้วยอีเมล) | ฟรีระดับเริ่มต้น สิทธิ์ต่อแถว (RLS) แยกวงได้ | สร้างโปรเจกต์ แล้วส่ง Project URL กับ anon key ที่เปิดเผยได้ จากนั้นรันสคริปต์ตารางที่จะเตรียมให้ |
| Firebase (Firestore + Auth) | โครงสร้างคล้ายที่เก็บข้อมูลที่แอปใช้อยู่ ทำให้แก้โค้ดน้อย | สร้างโปรเจกต์ เปิด Auth และ Firestore แล้วส่ง config ของเว็บ |

ทั้งสองแบบ: ชั้นข้อมูลของแอปแยกไว้แล้ว ถ้าได้โปรเจกต์ก็เพิ่มตัวเชื่อมต่อได้ แต่จะยังไม่นับว่าเสร็จ จนกว่าจะได้ทดสอบกับฐานข้อมูลจริง

# คอร์ดเลื่อนตามเพลง

เว็บชีทคอร์ดสำหรับเล่นบนเวที กดเล่นแล้วเนื้อเพลงจะเลื่อนทีละบรรทัดตามจังหวะ (BPM)
และบอกว่าตอนนี้อยู่ท่อนไหน ท่อนต่อไปคืออะไร

## เปิดใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไฟล์เดียวจบ ไม่ต้องลงโปรแกรม)

## โครงสร้างโฟลเดอร์
```
chord-scroller/
├── setlists/            ← แต่ละโฟลเดอร์ = 1 กลุ่มเพลง (1 งาน)
│   └── ITD/             ← งาน ITD 12 เพลง
│       ├── 01-ก่อนตาย.json
│       ├── 02-คุกเข่า.json
│       └── ...
├── template.html        ← หน้าตาและการทำงานของเว็บ
├── build.py             ← รวมทุกโฟลเดอร์เพลงเป็น index.html
└── index.html           ← ไฟล์เว็บที่สร้างเสร็จแล้ว
```

## เพิ่มกลุ่มเพลงใหม่
1. สร้างโฟลเดอร์ใหม่ใน `setlists/` เช่น `setlists/งานแต่ง-ธันวา/`
2. คัดลอกไฟล์เพลง (.json) ที่ต้องการมาใส่ ตั้งชื่อขึ้นต้นด้วย `01-`, `02-` ... ตามลำดับที่จะเล่น
3. รัน `python3 build.py` แล้วเปิด `index.html` ใหม่

## รูปแบบไฟล์เพลง (.json)
```json
{
  "title": "ห้ามใจ", "artist": "Bodyslam", "bpm": 80,
  "blocks": [
    {"type": "instru", "label": "INTRO", "bars": ["Em", "Em", "C", "C"], "note": "( 2 Times )"},
    {"type": "lines", "lines": [
      [["Em", "สุดท้าย.. ต่อให้เหนี่ยว "], ["Am", "รั้งสักเท่าไหร่ แต่ "], ["Bm", "โลกก็ต้องหมุน"]]
    ]},
    {"type": "note", "text": "( ซ้ำ * , ** )"}
  ]
}
```
- แต่ละบรรทัดคือรายการ `[คอร์ด, เนื้อร้องที่อยู่ใต้คอร์ดนั้น]`
- ย่อหน้าที่ขึ้นต้นด้วย `*` / `**` จะถูกตั้งชื่อเป็นท่อนฮุคให้อัตโนมัติ
- `( ซ้ำ * )` จะถูกกางท่อนที่ซ้ำออกมาให้เอง

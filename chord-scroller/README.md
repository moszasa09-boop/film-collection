# คอร์ดเลื่อนตามเพลง

ชีทคอร์ด 12 เพลง เปิดแล้วกดเล่น เนื้อเพลงจะเลื่อนตามจังหวะ (BPM) และบอกว่ากำลังอยู่ท่อนไหน

- `index.html` คือหน้าเว็บที่สร้างเสร็จแล้ว เปิดบนเบราว์เซอร์ได้เลย
- `songs/*.json` คือคอร์ดและเนื้อเพลงของแต่ละเพลง
- ถ้าแก้คอร์ดหรือเพิ่มเพลง ให้รัน `python3 build.py index.html` เพื่อสร้าง `index.html` ใหม่

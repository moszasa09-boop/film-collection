# คอร์ดเลื่อนตามเพลง

แอปชีทคอร์ดสำหรับวงดนตรี: จัดงานและเซ็ตลิสต์ เพิ่มเพลงจากรูปหรือข้อความ แล้วเล่นบนเวทีแบบเนื้อเพลงเลื่อนทีละบรรทัดตาม BPM บอกท่อนที่เล่นอยู่และเพลงถัดไป

- **ลิงก์สาธารณะ (ใครก็เปิดได้):** https://moszasa09-boop.github.io/film-collection/
  ทุกเครื่องดึง “ฉบับของวง” (`band-data.json`) มาเอง จึงเห็นงานและเพลงเหมือนกัน คนจัดงานเผยแพร่ฉบับใหม่จากหน้า “แชร์และสำรอง”
  ถ้าตั้ง Supabase ไว้ (`docs/SUPABASE.md`) สมาชิกล็อกอินแล้วแก้ได้ทุกเครื่องและเห็นกันทันที
- **ลิงก์ของวงบน claude.ai:** https://claude.ai/artifact/URe4f86jY5CjJcuQGaM57q
  ข้อมูลกลางที่ทั้งวงเห็นตรงกัน แยกสิทธิ์ดู/แก้ และอ่านคอร์ดจากรูปได้

ความต้องการทั้งหมด สถานะ ผลตรวจรายเพลง และข้อจำกัด อยู่ใน [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)

## โครงสร้าง
```
chord-scroller/
├── index.html        ← แอปที่สร้างเสร็จแล้ว (ไฟล์เดียว) ที่ GitHub Pages เปิดให้
├── build.py          ← รวม src/ กับ setlists/ เป็น index.html
├── src/
│   ├── page.html     ← โครงหน้า
│   ├── style.css     ← หน้าตา (โหมดสว่าง/มืด)
│   └── js/           ← โค้ดแอป เรียงตามหมายเลขไฟล์
│       ├── 00-localdb.js   ที่เก็บข้อมูลในเครื่อง (ใช้ตอนเปิดนอก claude.ai)
│       ├── 02-music.js     คอร์ด เปลี่ยนคีย์ ท่อน เวลา
│       ├── 03-format.js    รูปแบบข้อความเพลง ตัวแปลงคอร์ดบรรทัดบน ตรวจข้อมูล
│       ├── 04-store.js     ข้อมูลเพลง/งาน/เซ็ต การบันทึกและสถานะ
│       ├── 06-views.js     หน้างาน คลังเพลง
│       ├── 07-event.js     หน้างานเดียว เซ็ต ลากเรียง
│       ├── 08-editor.js    เพิ่ม/แก้เพลง อ่านจากรูป
│       ├── 09-player.js    เครื่องเล่น
│       └── 10-data.js      แชร์ สำรอง กู้คืน
├── setlists/        ← งานตั้งต้น: เบรค-1/ (10 เพลง) และ เบรค-2/ (12 เพลง) ลำดับและคนร้องอยู่ใน _event.json
│                      แต่ละไฟล์มีรหัสเพลงถาวร "id" · ไฟล์ที่มี "ref": true ชี้ไปเพลงในโฟลเดอร์อื่น
├── tools/make-band-data.js ← สร้าง band-data.json (ฉบับของวง) จากงานตั้งต้น
├── tests/            ← ชุดทดสอบ (Playwright + Chromium)
└── docs/             ← ความต้องการ สถานะ และผลทดสอบล่าสุด
```

## สร้างและทดสอบ
```bash
python3 build.py
```
```bash
python3 build.py --artifact
```
```bash
node tests/unit.js
```
```bash
node tests/e2e.js
```

ถ้าแก้เพลงหรือลำดับใน `setlists/` ให้สร้าง `band-data.json` ใหม่ด้วย เพื่อให้เครื่องที่เคยเปิดลิงก์แล้วได้ของใหม่:
```bash
node tools/make-band-data.js
```

คำสั่งแรกสร้าง `index.html` ส่วนคำสั่งที่สองสร้าง `chords.html` สำหรับอัปเดตลิงก์ claude.ai ชุดทดสอบต้องมี Playwright และ Chromium

## รูปแบบข้อความเพลง
```
[INTRO] | Em | Em | C | C | ( 2 Times )
## ฮุค
[Em]สุดท้าย.. ต่อให้เหนี่ยว [Am]รั้งสักเท่าไหร่
> ( ซ้ำ * , ** )
[Am?]  {?คำ}
```
- ใส่คอร์ดในวงเล็บเหลี่ยมไว้หน้าพยางค์ที่อยู่ใต้คอร์ด
- เว้นบรรทัดว่างเพื่อขึ้นท่อนใหม่
- `##` ใช้ตั้งชื่อท่อน
- `>` ใช้เขียนหมายเหตุ
- `?` แปลว่าอ่านไม่ชัด ต้องตรวจก่อนใช้
